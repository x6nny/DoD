# A collection of Data-Oriented utility modules for ROBLOX
---
Moves away from the metatable options, bringing more performance.

# Party
---
A simple party helper-module. Does not include remote for party invites, only handles removing, adding, ready and unready, and to check if all players are ready.

# Signal
---
A basic signal implementation, basically only wrapping BindableEvents without instances.

# State
---
A simple state module to write, read, and listen to state changes.
